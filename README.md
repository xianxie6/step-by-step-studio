# 一步一步画室

一间可以转来转去的 3D 画室。拖动进度条，看一幅画从第一根线到签名是怎么一步步画出来的，再自己动手画一张。

**在线体验：** https://xianxie6.github.io/step-by-step-studio/

## 三件作品

| 作品 | 画种 | 学到什么 |
| --- | --- | --- |
| 石膏球体 | 素描 | 定位构图、切方找形、五大调子（高光、灰面、明暗交界线、反光、投影） |
| 红苹果 | 水粉 | 从大到小、从深到浅，冷暖对比，环境色，边缘虚实 |
| 青花与柠檬 | 油画 | 薄涂底色、单色底稿、湿接湿、厚涂、刮刀、罩染 |

## 能做什么

- 拖动、缩放 3D 画室；铅笔、画笔、刮刀会立在画布上一笔一笔地画
- 每一步都有讲解和小窍门，“写生视角”小窗在静物上标出光源方向、交界线、高光、反光、投影
- “画纸”视图放大看排线和笔触
- “自己动手画一张”：素描铅笔 2H–8B、水粉 8 色、油画 8 色加刮刀，可开“临摹参考”
- 键盘：`←` `→` 切换步骤，`空格` 自动播放

## 技术

单个 `index.html`，用 [three.js](https://threejs.org/) 渲染画室；所有画面都是用 Canvas 程序化画出来的，没有图片素材。直接用浏览器打开 `index.html` 也能运行（需要联网加载 three.js 和字体）。
