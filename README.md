# 一步一步画室

一间可以转来转去的 3D 画室。拖动进度条，看一幅画从第一根线到签名是怎么一步步画出来的，再自己动手画一张。

**在线体验：** https://xianxie6.github.io/step-by-step-studio/

## 15 节课程

三个画种，每个画种 5 节课，从易到难：

| 画种 | 难度 | 课程 | 画什么 | 学什么 |
| --- | --- | --- | --- | --- |
| 素描 | 入门 | 石膏球体 | 一个石膏球 | 五大调子：高光、灰面、明暗交界线、反光、投影 |
| 素描 | 基础 | 几何体组合 | 正方体 + 圆锥 + 球体 | 方、尖、圆的明暗，透视与遮挡 |
| 素描 | 进阶 | 陶罐与苹果 | 陶罐 + 苹果 + 衬布 | 组合构图，不同质感的高光 |
| 素描 | 进阶 | 风景速写 | 大树、小路、远山 | 三分法，近实远虚 |
| 素描 | 挑战 | 石膏头像 | 四分之三侧面的石膏像 | 三庭五眼，眼窝与鼻底的投影 |
| 水粉 | 入门 | 红苹果 | 一个苹果 | 冷暖对比、环境色、边缘虚实 |
| 水粉 | 基础 | 苹果与陶罐 | 陶罐 + 红苹果 + 青苹果 | 主次关系，固有色不同、明暗规律相同 |
| 水粉 | 进阶 | 酒瓶与水果 | 酒瓶 + 白瓷盘 + 橙子 + 梨 + 柠檬 | 多物体构图，玻璃与白盘子的颜色 |
| 水粉 | 进阶 | 湖边夕照 | 夕阳、远山、湖面倒影、逆光的树 | 天空渐变，倒影比实景暗，逆光剪影 |
| 水粉 | 挑战 | 色彩头像 | 有肤色和头发的头像 | 肤色“三段色”，冷背景衬暖肤色 |
| 油画 | 入门 | 青花与柠檬 | 青花瓷瓶 + 柠檬 | 薄涂、湿接湿、厚涂、刮刀、罩染 |
| 油画 | 基础 | 铜壶与洋葱 | 铜壶 + 两个洋葱 | 金属质感：强对比、锋利的高光、映出环境 |
| 油画 | 进阶 | 荷兰静物 | 酒瓶 + 一串葡萄 + 面包 | 古典暗背景，葡萄先整后零 |
| 油画 | 进阶 | 麦田与云 | 积云、金色麦田、柏树 | 印象派笔触并置，厚涂的光 |
| 油画 | 挑战 | 伦勃朗光肖像 | 侧光头像、深背景 | 伦勃朗光，暗部薄、亮部厚，金褐色调 |

静物和头像课：3D 画室里摆着真实的物体，画面是从画家的位置“拍”下来再一笔笔画出的。风景课：静物台上立着一张参考照片，按从远到近的顺序画。

## 能做什么

- 拖动、缩放 3D 画室；铅笔、画笔、刮刀会立在画布上一笔一笔地画
- 每一步都有讲解和小窍门，“写生视角”小窗在静物上标出光源方向、交界线、高光、反光、投影
- “画纸”视图放大看排线和笔触
- “自己动手画一张”：素描铅笔 2H–8B、水粉 8 色、油画 8 色加刮刀，可开“临摹参考”
- 键盘：`←` `→` 切换步骤，`空格` 自动播放

## 技术

单个 `index.html`，用 [three.js](https://threejs.org/) 渲染画室。静物和头像用距离场搭出来，从画家的视角做光线步进，算出每个像素的明暗、投影和高光，再按画种的步骤用 Canvas 一笔笔画出来；风景是分层的程序画面。没有任何图片素材。直接用浏览器打开 `index.html` 也能运行（需要联网加载 three.js 和字体）。
